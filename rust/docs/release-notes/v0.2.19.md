# Sudo Code v0.2.19

## Added

- `agent_list` discovers addressable agents and running sub-agents in one place. It shows whether each agent is active and includes a PID for running sub-agents; inactive peers can still receive messages for later delivery.
- Choosing “Clear context & execute” after approving a `write_plan` starts a fresh session with the approved plan and the existing todo list, rather than losing the todos. The approval dialog shows the full plan and reports which option was chosen.

## Changed

- CLI sessions and co-hosted agents now use the same engine and kernel-backed filesystem. The CLI kernel runs locally without a daemon, mounts the workspace and configured `additionalDirectories`, and refuses file-tool paths outside those mounts. CLI paths retain their host spelling; changes to mounted files remain visible to external editors.
- Compaction retries now use typed error classification instead of inspecting error messages, preserving the existing retry decisions.

## Fixed

- Pasting into the DialPad’s custom-input row now accepts bracketed and multiline text.
- `scode config set` recognizes the keys it offers instead of writing settings that fail validation and cause other settings to fall back to defaults.
- The local mailbox poller uses the session’s agent identity, including when its workspace is accessed through a symlink.

## Validation

The release includes filesystem-boundary and path-round-trip tests for CLI sessions, plus a secret-free mocked co-host test that exercises an agent reading through the kernel and replying over the mailbox. It also adds coverage for plan/todo continuity, DialPad paste, and typed compaction retries, and stabilizes live PTY checks.

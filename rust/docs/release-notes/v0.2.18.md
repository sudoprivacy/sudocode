# Sudo Code v0.2.18

## Added

- A Bocha web search provider. Set `web_search.provider` to `bocha` with
  `BOCHA_API_KEY` (or `web_search.apiKey`); `SUDOCODE_BOCHA_API_URL` overrides
  the endpoint. See `docs/usage.md` § Web search with Bocha.
- Screenshots and image inputs reach the active vision model natively, instead
  of being routed through a fixed provider.

## Changed

- Model-facing `bash` results are compact JSON: `stdout`, the real `exit_code`,
  and `stderr` only when nonempty. Empty fields and routine sandbox capability
  flags are dropped; failures keep `returnCodeInterpretation`, interrupted runs
  keep `interrupted`, and background launches keep `backgroundTaskId` without
  claiming an exit code. The full struct stays available internally and the
  compact text is persisted before it reaches the provider, so a resumed
  session sends identical results. See `docs/usage.md` § Bash tool results.
- Nexus VFS is updated for multi-mount federation: a zone mounted at more than
  one path no longer collapses to a single mount point, which previously let a
  cross-node unlink dispatch to a peer instead of the local disk.
- Cloudflare 525 (SSL handshake failed) joins 520, 522, 524 and 529 as a
  retryable status. A bodied 525 used to abort the turn without a retry.

## Fixed

- Typing directly on a DialPad's `[+]` row no longer drops characters. The
  custom-input row is now part of the DialPad itself, so a multi-character
  answer typed without pressing Enter first arrives whole.

## Internal

- Error taxonomy phase 1: `ErrorAction { Transport, Model, Human, Fatal }` and
  `ApiError::action()` are the single classifier; `is_retryable()` is a
  projection of it, and the duplicated masked-400 checks collapse into one
  source. Behavior-preserving. See `docs/design/error-taxonomy.html`.

## Validation

The release adds PTY coverage for compact bash results, for Bocha search, and
for DialPad custom input, plus expanded image-handling coverage and an
equivalence test asserting the rewritten retry set matches the old one across
every error variant.

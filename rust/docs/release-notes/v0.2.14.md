# Sudo Code v0.2.14

## Changed

**Plan approval is now a first-class tool flow.** Agents write implementation
plans through `write_plan`, which presents the approach for approval before
non-trivial work begins. The former plan-mode aliases have been removed.

**Queued work and active tools share one pending overlay.** The REPL now keeps
queued human and agent-to-agent input visible in a unified overlay while a turn
is active, without rewriting the transcript.

## Improved

- Mailbox paths now use a single per-recipient model and a canonical local agent
  identity, improving same-machine agent-to-agent message delivery.
- The status line shows compact token and cost units plus cumulative per-session
  totals and duration.
- The Nexus VFS worker reply wait is bounded, preventing a stalled worker reply
  from blocking indefinitely.

## Documentation

- Matrix message-correction guidance is consistent throughout the documentation.

## Validation

The release includes integration coverage for the plan approval flow, mailbox
routing, and unified pending overlay, along with stabilized live PTY readiness,
turn-gating, and resume coverage.

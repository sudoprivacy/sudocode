# Sudo Code v0.2.13

## Changed

**Queued input stays out of scrollback.** Input submitted while a turn is in
progress is held in a queue overlay, keeping the transcript readable and making
queued work visible without rewriting prior output. The REPL no longer
auto-interrupts an active turn; queued input is processed in order.

## Improved

- The live PTY coverage is more stable across platforms and terminal timing.
- PTY tests share stronger readiness and cleanup coordination, reducing flakes in
  arrow-key, bracketed-paste, cancellation, compaction, and resume scenarios.

## Validation

The release includes the stabilized live PTY test coverage and queue-overlay
integration coverage added since v0.2.12.

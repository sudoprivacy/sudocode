# Sudo Code v0.2.9

## What's New

This release is mostly about agent-to-agent messaging and the REPL's feedback
surfaces. Sub-agents and peers now talk through one unified `send` tool and a
durable mailbox; tool calls render as a single L-frame card; and the per-turn
status line tells you the truth about cost and KV-cache reuse.

## Added

**Unified `send` + durable mailbox for agent-to-agent messaging.** One `send`
tool (with tool aliases) replaces the scattered send paths. A recipient's name
resolves which mailbox the envelope is written through, inboxes are created on
send instead of being clobbered, and a durable receive cursor waits for the
consumer so no message is dropped between handoffs. Sub-agent → parent
messaging is delivered by a local JSONL inbox poller, and an incoming
`PeerMessage` is injected as a real LLM turn rather than only printed.

**Deferred tools (Claude Code parity).** Tools can be advertised by name and
their full schema fetched on demand, so the model sees exactly one name per
capability. `agent_spawn` gains auto-resume (with a `fresh` flag), `pid_output`
gains a merge flag and surfaces the session path, and the agent-type catalog is
delivered to the model as `<available-agent-types>`.

**KV-cache efficiency in the status line.** Each turn now shows a compact
`⚡NN% ✎NN%` segment — cache hit rate and cache-write rate over the turn's
prompt — colored by tier so a broken-cache turn stands out. Useful when tuning
prompt-cache reuse.

**Tool rendering unified into an L-frame card** with a staging overlay, so tool
calls and their results read as one coherent block instead of scattered lines.

## Fixed

**The per-turn cost/tokens now bill the whole turn.** A turn that makes several
model requests (the tool-call loop) was reporting only the last request's
tokens and cost; it now sums the whole turn. The `ctx` occupancy segment still
tracks the latest request (the metric auto-compaction uses).

**Cost shows the real billed amount when the gateway reports one.** The status
line prefers the gateway's actual charge and falls back to a per-model estimate
(marked with a leading `~`) only when no real cost is reported — instead of
always estimating with a fixed price table.

**`AskUserQuestion` accepts `question` as an alias for a per-item `prompt`**, so
a structured question written the natural way no longer fails the whole call
with `missing field prompt`.

**Interactive pickers accept a free-form answer.** DialPad and FuzzySelect
question prompts now honor `allow_custom_input`: type an answer that is not one
of the listed options (e.g. a model name `/model` does not list) and it is
accepted.

**The turn status line no longer double-prints.** It renders once in the
chrome, not also in scrollback.

**Claude stays on the Anthropic path** when the SSOT has no endpoint type, and a
range of send/mailbox, prompt-assembly, and REPL input-handling bugs are fixed
(see the commit log for the full list).

## Notes

Pairs with `sudoprivacy/new-api#11`, which makes the gateway report real
`cost_units` on the Claude-native path; once deployed, the status line shows the
real charge (no `~`).

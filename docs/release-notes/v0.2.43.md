# Sudo Code 0.2.43

A peer message reaches every kind of agent through that agent's own input
queue, the one its user's messages use, and stays unread in the Nexus mailbox
until the receiving model acknowledges it. ACP clients that declare
`peerInput` version 3 read mailbox offers themselves: scode renders each
conversation's unread frames within the client's byte bound, binds a token to
each frame's exact content, and commits a frame only when that token comes
back. A large frame is read in further windows instead of being refused.
Versions 1 and 2 remain available.

The `@sudocode/acp` Claude Code bridge uses version 3. `SessionStart` and
`CwdChanged` hooks have Claude Code watch the session's private spool, and a
`FileChanged` hook with `asyncRewake` hands each budgeted delivery to Claude
within the current turn or wakes an idle session. Each delivery stays within
Claude Code's 10,000-character hook output cap; the model reads further windows
and acknowledges frames with `scode_inbox`. The earlier `--claude-wake` hook
and the fixed-session channel mode are removed. Codex gains the same bounded
offer and acknowledgement primitives, and installation checks the native
receiver's capability before it changes any registration.

A2A delivery recovers after receiver, proxy and native transport disconnects
with its original actor, session and message identity. Agent enrollment
resumes an operation that failed after its credential was issued, binds each
operation to its identity rather than the operator record's bytes, and
publishes the operator's current launch policy, such as a new scode path, to
already enrolled actors. Only interactive Claude Code sessions join the agent
network, and a session started while its Node is unreachable joins once the
Node returns. In shared mode, a new interactive or ACP scode session in a
workspace joins its user's local Box on first use: the Box issues the session's
own workspace-derived Agent credential. When that cannot happen, the footer,
`/status` and `scode setup --check` give the cause and the command that fixes
it; `scode setup --mode shared` also joins a workspace with a configured
`agentName`.

`/model`, `/effort`, `/help` and `/tasks` work while a turn runs: help and
tasks open at once, and a model or effort choice applies when the turn ends.
Other slash commands typed during a turn are refused by name, and none of them
reaches the model.

Reclaiming an already reclaimed Session no longer touches storage. A link
whose read-back misses because of replica lag is reported as lag, not as an
old daemon. Long todo items wrap under their text, and a collapsed paste stays
distinct on the shaded prompt. The macOS setup wizard configures only the
named SudoRouter account and an explicitly selected model, and leaves model
discovery, protocol and capabilities to the runtime. The toolchain is Rust
1.100.0.

Linux and macOS release binaries ship stripped, about 30% smaller. Their
symbols are published as separate `symbols-<package>.tar.gz` assets on the
GitHub release; the checksummed install set is unchanged.

The CLI and paired co-host keep Nexus `v0.8.29-rc.8`.

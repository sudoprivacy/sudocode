# Sudo Code v0.2.17

## Added

- A2A conversations are addressed by conversation, with chat-list indexing shared across backends.

## Changed

- Coordinator notifications now use the conversation-owned queue.
- Nexus VFS is updated for the portable chat-list index.
- Retryable HTTP status handling has one shared source and includes 520, 522, 524 and 529.

## Improved

- REPL prompts, including write-plan approval and interactive permission prompts, consistently use the shared editor.
- Running tool cards remain overlay-only until completion, keeping scrollback stable.

## Validation

The release includes A2A conversation and mailbox coverage, live PTY coverage for interactive prompts, and tests for rendering and retryable HTTP statuses.

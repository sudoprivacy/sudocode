# Sudo Code 0.2.42

`agent_list` now observes independent CLI and cohost runtime instances using
shared engine lifecycle facts and the background-task registry. Input waits and
background work remain distinct, multiple instances of one Agent/SID are
preserved, and unavailable or stale observations remain unknown. Status queries
start no model turn and do not read conversation history.

Deleting a Session on a native filesystem now retires its managed storage
handles while idle runtimes, completion journals and HTTP response objects
remain alive. Automatic cleanup waits for actual admitted I/O to finish, then
reclaims the Session's owned storage. Legacy and record histories use the same
durable deletion decision. Independent project writes retain their own lifetime.

The CLI and paired co-host use Nexus `v0.8.29-rc.8`. This includes permanent
record ownership, guarded content operations, storage I/O lifetime controls and
registration incarnations for the versioned external-runtime API. PID encoding
remains `OS PID[.local_id]` within its execution domain.
The shared native Windows file publisher also includes the corrected filename
buffer used when publishing node identity and durable state.

Remote Session completion and deletion remain capability-guarded pending their
full ownership, WAL, ACK and automatic reclamation integration. Shared-history
defaults retain their existing behavior.


# Sudo Code v0.2.16

## Added

- ACP clients can follow sub-agents live. A client that sets
  `clientCapabilities._meta.sudocode.subagentEvents` at `initialize` receives
  each sub-agent's text, thinking and tool calls on the parent session. Each
  agent also reports a `started` / `finished` lifecycle, so the final result
  of a background agent arrives even after the parent's turn has ended. The
  new `_sudocode/agent/cancel` request stops one running agent. Without the
  opt-in, the ACP output is unchanged. See `docs/acp.md` § Sub-agent events.
- `!` bash mode: prefixing a prompt with `!` runs a shell command directly,
  without a model turn. It works in the REPL and over ACP.

## Fixed

- Stopping a sub-agent now interrupts the tool it is running. Before, a
  cancelled or shut-down sub-agent waited for its current `bash`, `Sleep`,
  `grep_search` or `PowerShell` call to finish on its own.

## Validation

The release adds ACP coverage for sub-agent events in synchronous, parallel
background and nested runs, and for cancellation. When the client does not
opt in, the output is compared against fixtures captured before the feature
existed. There is also PTY and ACP coverage for `!` bash mode.

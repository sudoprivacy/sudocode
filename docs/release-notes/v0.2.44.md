# Sudo Code 0.2.44

`agent_list` tells which peers are online. Each row carries one `active` bit:
a peer seen online in its zone, or a running subagent task, and `active_only`
keeps those rows. Every member of a zone may read a peer's bit, as it may list
the zone's Agents; no other runtime fact is shared with peers. The per-instance
runtime rows and their coverage fields are removed. Peer descriptions are shown
by default.

In shared (multi-agent) mode a new session joins the local Box on its own when
the OS user owns that Box, instead of waiting for its Agent name to be minted
by hand. The A2A prompt no longer spells out the peer-message envelope.

The REPL wraps prose between words, hanging under its own text, and every live
row starts right of one shared gutter. Compaction and queued input are visible
while they run, session slash commands typed during a turn wait until it ends,
and running tasks use the brand accent in the task list. A background child's
approval request holds attention in its idle parent and in navigation until it
is answered.

A builtin `vault` plugin, disabled by default, lists the Vault operations the
owner configured and whether each secret is readable.

The Claude Code bridge keeps its ten-minute delivery spacing across a momentary
unread count of zero.

The CLI and paired co-host use Nexus `v0.8.29-rc.10`. It adds zone presence;
rc.9 brought the managed-agent cleanup latch and the managed child entry.

# Sudo Code v0.2.23

## Changed

- The default Claude model is now `claude-opus-5` (previously `claude-opus-4-8`). The `opus` / `claude-opus` alias follows that default instead of naming a generation of its own, so `scode` and `scode --model opus` resolve to the same model. `sonnet` and `haiku` continue to select their own families. Set `model` in `.nexus/sudocode/settings.json` or pass `--model` to pin a different one.
- Streamed tools are scheduled through one lifecycle, and interactive replies are asynchronous and turn-safe.
- Received peer messages are distinguishable from your own input in transcripts.

## Fixed

- Windows gets colour and `~` path expansion without extra configuration: an unset `TERM` no longer reads as "no colour", and `~` resolves to the user profile.
- Windows verbatim paths written with forward slashes are accepted.
- Concurrent tool execution and cancellation are enforced safely.
- Explicit stream completion is honoured even when it arrives across split frames.
- A real terminal resize preserves scrollback history and the current input.
- The spinner pauses in step with active drawing, and spinner activity is tracked so it reflects real work.
- Prompt edits apply before later input events rather than being overwritten by them.
- Pending tool frames stay whole and report the actual execution state.
- Tool titles and list layout are tightened; transcript block spacing follows one shared policy, and info colours resolve through `ColorTheme`.
- Shell diffs reuse the Edit colours.
- Linux release bundles are mirrored, and a stable publication can be resumed from its existing assets.

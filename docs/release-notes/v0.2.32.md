# Sudo Code 0.2.32

Linux ARM64 releases now include a self-contained installer bundle and a Debian
package alongside the existing standalone executable. The bundle uses the same
`scode-setup` installation and removal workflow as x64; the Debian package
advertises `arm64` and its glibc 2.35 and libgcc runtime requirements.

Release CI builds ARM64 natively on Ubuntu 22.04, verifies the bundle checksums,
executes the extracted Debian payload, and installs, runs and removes the bundle
before publishing. Both installers are covered by the release checksum manifest
and stable Tencent COS mirror. x64 remains a static musl executable.

The paired `nexusd-cohost-v0.2.32` release uses the same source revision and the
existing Nexus v0.8.15 dependency pin.

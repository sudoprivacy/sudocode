# Sudo Code v0.2.21

## Fixed

- Cancelling or timing out a foreground Bash tool now terminates its process tree on Windows and Unix. ACP cancellation and interactive Escape no longer leave shell descendants running; a subsequent turn can continue in the same session.
- Truncated model streams report a failure instead of looking like a completed answer. Transport errors retain their underlying cause, and provider connections handle closed sockets and unframed responses.
- Model capabilities are discovered for the active endpoint and credentials. Bundled capabilities take precedence over stale fallback files; undocumented context windows are no longer invented.
- Thinking blocks, request fields, and sub-agent routing credentials survive tool turns and cache-safe compaction. Prompt cache storage respects the configured home.
- Terminal resizing preserves history and input, live chrome retains text styles, and repeatedly recalling queued messages preserves the queue.

## Changed

- Co-hosted agents send model requests through their session's Nexus model mount. The kernel dependency is pinned to nexus-vfs v0.7.26, which includes the replicated-tail deadlock fix.
- Chat-list indexes use links on both local and Nexus filesystems.

## Regression coverage

Live API PTY tests exercise cancellation and timeout with a real grandchild process, require that process to exit, and verify a file-producing follow-up turn. CI runs these workflows on Windows and Linux. Sudowork's companion ACP suite covers file operations, idle continuation, cancellation, process cleanup, and session recovery through a real Nexus daemon.

# Sudo Code 0.2.45

When using the OpenAI-compatible API with `deepseek-flash`, scode now
includes the reasoning returned by earlier assistant turns in subsequent
requests. This fixes HTTP 400 responses during tool-enabled conversations.

Since 0.2.44, scode has also gained A2A setup for Claude Code and Codex.
Wrapped prompt history follows the text gutter, and the Windows terminal
keeps drafts across a queued paste and a resize.

# Sudo Code v0.2.15

## Changed

- A2A receive paths now make repeated delivery explicit so the model can
  decide how to handle duplicate messages.
- The A2A send flow is always visible and uses one shared guidance source.
- Bash tool cards show the full command when the card header is truncated.

## Improved

- Mailbox messages retain their send timestamp on every delivery path.
- Nexus VFS client requests apply deadlines consistently and keep a bounded
  backstop for silent daemons.
- REPL scrollback leaves a blank line after A2A and input echoes.

## Validation

The release includes end-to-end coverage for silent-daemon deadline handling,
A2A delivery and rendering, and the updated write-plan flow.
